# Scope of Work — UPHP-Style Claims & Enrollment Cost Analysis

**Data Analyst:** Vyshnavi Priya Kasarla
**Client/Sponsor:** UPHP Finance & Quality Team *(mock stakeholder, for practice)*

## Purpose
This project analyzes medical claims and enrollment data for a regional Medicaid-focused
health plan to identify which member segments drive the highest per-member cost, and
whether utilization patterns (e.g., ER vs. primary care use) suggest opportunities to
improve cost and access to care. The goal is to give the finance and quality teams a
clear, data-backed recommendation for where to target a care-coordination or outreach
program.

## Scope / Major Project Activities

| Activity | Description |
|---|---|
| Data Collection | Gather claims-level data (diagnosis, procedure, cost, member demographics) from the public claims dataset |
| Data Cleaning | Remove duplicates, standardize member/plan categories, handle missing values, flag outliers |
| Cost Segmentation | Calculate average and total cost per member segment |
| Utilization Analysis | Compare ER vs. primary care utilization rates across segments |
| Recommendation Dev | Identify the highest-cost, highest-opportunity segment and propose one actionable intervention |
| Final Report & Dashboard | Deliver a one-page summary report and supporting visualizations |

## This project does not include (out of scope)
- Real UPHP member data — this is a self-directed practice project using public synthetic data
- Any predictive modeling or machine learning — this is a descriptive/diagnostic analysis
- Implementation of any recommended interventions
- Claims data outside the scope of the selected dataset's time period

## Deliverables
