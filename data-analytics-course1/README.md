## Why this project
UPHP (Upper Peninsula Health Plan) is a Michigan managed-care organization whose data
analysts work with medical/pharmacy claims, hospital data, enrollment, and revenue to
support clinical, claims, and finance teams. This repo documents my learning and a
self-directed project built to practice those same skills using public data.

## Weekly workflow
1. Copy `weekly-log/WEEKLY_TEMPLATE.md` to `weekly-log/week-XX.md`.
2. Fill it in as you go through the week's course material.
3. When a course finishes, add its certificate PDF to `/certificates` and check it off
   in the table above.
4. Commit and push at the end of each week.
