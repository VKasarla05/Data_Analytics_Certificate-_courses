# Using AI in the Job Search

## Where AI helps
| Task | How AI helps |
|---|---|
| Exploring roles | Summarize job descriptions; compare required skills |
| Resume | Tailor bullets to a job posting; tighten wording |
| Cover letter | Draft a first version to personalize |
| LinkedIn | Improve headline and About section |
| Interview prep | Generate likely questions; practice answers |
| Networking | Draft outreach messages |

## Writing good prompts
- Give context: role, experience level, target job
- Paste the job description and your own material
- Ask for a specific output (e.g., "3 resume bullets with numbers")
- Iterate: ask for shorter, more specific, or a different tone

## Using AI responsibly
- **Verify everything:** AI can produce wrong or made-up details
- **Never claim skills or results you don't have**
- **Keep your own voice:** edit drafts so they sound like you
- **Protect privacy:** don't paste personal or confidential information
- Follow each employer's rules on AI use in applications

## Turning a project into job-search material
- **Resume bullet:** action + tool + result, e.g., *"Analyzed 558K Medicare claims in BigQuery SQL; found 5% of members drove 44% of cost and built a Power BI dashboard highlighting chronic-condition cost drivers."*
- **STAR story:** situation, task, action, result
- **2-minute pitch:** problem → data → method → finding → impact
