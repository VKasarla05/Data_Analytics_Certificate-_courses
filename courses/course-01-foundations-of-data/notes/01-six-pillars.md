# The Six Pillars of Data Analysis

A quick-reference framework for the end-to-end data analysis process.

| Pillar | What happens here |
|---|---|
| **Ask** | Understand the business challenge and ask questions to clarify scope and goals. |
| **Prepare** | Collect data, identify sources, gather and verify it. |
| **Process** | Clean and organize the data so it's ready for analysis. |
| **Analyze** | Dig into the data to find answers, patterns, and solutions. |
| **Share** | Present findings to decision-makers via reports and visualizations. |
| **Act** | Turn the insights into real, implemented decisions. |

## My takeaway
This is the loop I'll run through on every project in this repo, including the applied
case study — starting with a clear question, not with the data.
