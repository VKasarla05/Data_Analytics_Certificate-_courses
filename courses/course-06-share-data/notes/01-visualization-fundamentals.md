# Data Visualization Fundamentals

## Why visualize
A good visualization lets the audience understand data **quickly**. The goal is not decoration: it's making the key insight obvious.

## Four elements of successful visualizations (David McCandless)
| Element | Meaning |
|---|---|
| **Information** | The data you're working with |
| **Story** | A clear, compelling narrative the data supports |
| **Goal** | A specific objective the visual serves |
| **Visual form** | Effective use of metaphor and visual expression |

With only information + visual form you get a pretty sketch; you need all four for a successful visualization.

## Pre-attentive attributes
Visual properties the brain notices in milliseconds, before conscious thought:
- **Marks:** position, size, shape, color
- **Channels:** accuracy, popping out, grouping

Use them to guide attention, e.g., one highlighted bar in a gray chart.

## Choosing a chart
| Goal | Chart |
|---|---|
| Compare categories | Bar / column |
| Show change over time | Line |
| Part of a whole | Stacked bar (pie only for 2–3 parts) |
| Relationship between two numbers | Scatter |
| Distribution | Histogram |
| Geography | Map |
| Two measures on one axis | Combo (bar + line, dual axis) |

## Correlation vs. causation
A chart showing two things moving together does not prove one causes the other. Say "is associated with," not "causes," unless an experiment supports it.

## Static vs. dynamic visuals
- **Static:** fixed image (slides, reports); you control the story
- **Dynamic:** interactive (dashboards, filters); the viewer explores
